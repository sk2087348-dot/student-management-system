# Student Management System
A simple Student Management System built with the  Python and MySQL.
## Features
- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Input Validation
## Technologies Used

- Python
- MySQL
- MySQL Connector
## Database

MySQL database is used to store and manage student records.

## Functionality

- Add new student records
- View all student records
- Search students by name
- Update student name and age
- Delete student records
- Validate user input

## Project Structure

Student Management System/
│
├── student_management.py
└── README.md
## How to Run

1. Install Python
2. Install MySQL
3. Install MySQL Connector:
   `pip install mysql-connector-python`
4. Create the `management_system` database in MySQL
5. Run the Python file
